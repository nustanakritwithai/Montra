# MONTRA — วิชาอาชีพช่วงเลเวลสูงรุ่นทดลอง

วิชาในเอกสารนี้เป็นการออกแบบสำหรับเกม ค่าพลัง ระยะ กำลัง คูลดาวน์ และเงื่อนไขฝึกเป็นค่าทดลองที่ต้องปรับจากการเล่นจริง ผู้เล่นยังใช้อาชีพเดิมและแต้มกองเดิม วิชาที่เรียนแล้วจัดลงช่องลัดตามตำราได้ ต้องเรียนวิชาก่อนหน้าและทำผลฝึกตามที่ตำราแสดง

- **คมดาบ:** Lv.35 คมเงาสะท้อน, Lv.55 ผ่ารอยผนึก, Lv.75 เงาสวนคม และ Lv.95 สะบั้นผนึกเงา เชื่อมการเปิดฉาก รอยอาคม และการหลบสวน ท่าใช้รอยยังต้องมีรอยจากผู้ใช้บนเป้าหมายจริง
- **ผู้พิทักษ์:** Lv.35 มั่นคงรับศึก, Lv.55 กวาดพิทักษ์แนว, Lv.75 ง้าวสวนรักษาแนว และ Lv.95 แนวคุ้มครองมั่นคง วิชาป้องกันตนเองและฝึกสกัดช่วยให้เรียนสายนี้ขณะเล่นคนเดียวได้
- **นักดาบไทย:** Lv.35 เพลงดาบสืบจังหวะ, Lv.55 วงดาบเปิดแนว, Lv.75 รับดาบมั่นคง และ Lv.95 เพลงดาบสวนสุดท้าย เป็นวิชาร่วมทุกสำนัก ใช้ดาบคู่และยังต้องผ่านเงื่อนไขรับสวน/คอมโบของเกม
- **มวยไทยโบราณ:** แต่ละสำนักมีวิชาใหม่ Lv.40, 80 และ 95 ไชยาเน้นรับสวน โคราชหมัดหนัก ลพบุรีฉากเข้าสวน และท่าเสาก้าวกับหมัดต่อเนื่อง ต้องฝึกโจมตี รับ และผลฝึกประจำสำนักตามตำรา ชื่อท่าเป็นแนวคิดสำหรับเกม ไม่ใช่คำรับรองท่าประวัติศาสตร์
- **ผู้ร่ายเวท:** Lv.35 ข้าวสารเพลิงอาคม, Lv.55 คุณไสยกัดวิญญาณ, Lv.75 ระเบิดตราผนึก และ Lv.95 สายฝนข้าวสารอาคม เชื่อมข้าวสาร คำสาป และตราของตน การโจมตีหลายเป้าใช้กฎระยะและแนวยิงเดิม
- **ผู้เยียวยา:** Lv.35 ยันต์ประคองชีพ, Lv.55 เขตยันต์คุ้มชีพ, Lv.75 วงยันต์ต่อชีพ และ Lv.95 ข้าวสารประคองวิญญาณ โดยข้าวสารใช้กับมอนสเตอร์เท่านั้น วิชารักษาตนเองและข้าวสารช่วยให้มีทางฝึกและล่าเดี่ยว

สกิลโจมตีที่ระบบรองรับสามารถนำแต้มไปอัปขั้นได้ตาม `SKILL-RANKS-TH.md` ตัวคูณอัปขั้นมีผลต่อมอนสเตอร์เท่านั้น ส่วนวิชาใหม่เองใช้กติกา PvE/PvP เดิมของประเภทวิชานั้น การรักษาและคุ้มครองเป็นวิชาที่ใช้กับตนเองหรือปาร์ตี้ตามกฎเดิม ค่าความสามารถใหม่ยังไม่ได้ปรับสมดุลจากการเล่น PvP จริง

`advanced-lessons.test.ts` ตรวจโครงสร้างวิชาจนถึง Lv.95 และงบแต้ม `advanced-class-integration.mjs` ตรวจตัวอย่างเรียน/ใช้วิชาช่วงสูงและเรียนวิชา Lv.95 ของทั้งหกสายบนเซิร์ฟเวอร์แยกเท่านั้น ไม่ถือว่าเป็นการเล่นครบทุกสกิลหรือยืนยันว่าสมดุลแล้ว

เซฟที่เรียนวิชาใหม่ต้องใช้เซิร์ฟเวอร์ที่รู้จักรหัสวิชานั้น เมื่อจำเป็นต้องกู้คืนให้ใช้รุ่นที่อ่านวิชาใหม่นี้ได้และสำรองเซฟล่าสุดแยก ห้ามนำเซิร์ฟเวอร์เก่าที่ไม่รู้จักวิชามาบันทึกทับ
