# MONTRA — บัพและการเข้าสิง (ค่าทดลอง)

ในสำเนารวมนี้ให้เรียกวิญญาณก่อนกดเข้าสิง เซิร์ฟเวอร์นำวิญญาณที่เรียกออกจากฉากและให้สถานะเข้าสิงแก่เจ้าของ 60 วินาที เพิ่ม ATK, DEF, Magic ATK และ Magic DEF ของตัวละครอย่างละ 20% โดยปัดเป็นจำนวนเต็ม บวกหลังคำนวณสเตตัสพื้นฐานและก่อนบวกโบนัสอาวุธ ไม่เพิ่ม HP, กำลัง หรือความเร็ว ค่าตั้งต้นอยู่ใน `SkillCatalog.ts` และต้องปรับจากการเล่นจริง

กดเข้าสิงอีกครั้งเพื่อยกเลิก บัพสิ้นสุดเมื่อหมดเวลา หมดสติ หรือออกจากห้อง ระหว่างเข้าสิงเรียกวิญญาณอีกตัวไม่ได้ และเมื่อสถานะสิ้นสุดจะรอ 30 วินาทีก่อนเข้าสิงอีกครั้ง ต้องเรียกวิญญาณใหม่ก่อนใช้ครั้งต่อไป คูลดาวน์ของตัวละครถาวรยังมีผลเมื่อออกเข้าใหม่ขณะที่ Node ตัวเดิมทำงาน แต่ยังไม่คงอยู่หลังรีสตาร์ต Node หรือข้ามหลายเซิร์ฟเวอร์ บัพไม่ถูกบันทึกในเซฟ เซิร์ฟเวอร์คำนวณจากค่าสเตตัสเดิมทุกครั้งเพื่อไม่ให้ทบซ้ำเมื่อเลเวลเปลี่ยน

การใช้งานออนไลน์: อัญเชิญวิญญาณ → กด เข้าสิง → ดูค่าสเตตัสในโปรไฟล์หรือกดปุ่มเดิมเพื่อยกเลิก หน้าเว็บและเซิร์ฟเวอร์ต้องใช้รุ่นที่รองรับ `buffsAvailable` ตรงกัน บัพนี้ยังไม่ใช่ระบบเลือกวิญญาณหลายชนิด ไม่มีบัพถาวรหรือระบบเก็บวิญญาณ

ตรวจ TypeScript ทั้งแบบ strict และ Windows production ผ่าน กฎบัพ 3 รายการผ่าน และทดสอบ Node/SQLite ในโฟลเดอร์ทดสอบแยก: ตรวจเงื่อนไขเรียกวิญญาณ โบนัส สั่งยกเลิก ห้ามเรียกซ้อน คืนค่าสเตตัส และคูลดาวน์หลังเข้าใหม่ ผลทดสอบแชทปาร์ตี้/ส่วนตัว/รายงานบัคบนสำเนารวมผ่านด้วย ทดสอบหมดเวลาผ่านนาฬิกาจำลองใน unit test ยังไม่ได้รอ 60 วินาทีจริง ยังไม่ได้ทดสอบหน้าเว็บในเบราว์เซอร์หรือ GitHub Actions
