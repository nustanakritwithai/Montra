# MONTRA V0.2.9 — แชทและการติดตั้งบน Windows VPS

แชทมีสองช่อง: **แผนที่** ส่งเฉพาะผู้เล่นในแผนที่เดียวกัน และ **รวมในห้อง** ส่งทุกแผนที่ภายใน Colyseus room เดียวกัน โดยยังไม่ส่งข้าม room ข้อความเก็บชั่วคราวในหน้าจอระหว่างเชื่อมต่อ ไม่เขียนลงเซฟตัวละคร

## ก่อนติดตั้ง

ตรวจว่าเวอร์ชันนี้ผ่าน CI และ merge แล้ว ตรวจ `MONTRA_CHARACTER_DIR` ที่ process MONTRA ใช้จริง สำรองโฟลเดอร์เซฟทั้งสามช่อง รวมทั้ง source และ build ไปยังที่ปลอดภัย และตรวจว่า backup เปิดอ่านได้ ติดตั้งช่วงไม่มีผู้เล่นทำธุรกรรม

ดาวน์โหลดตัวติดตั้ง `deploy/combat/install-windows.ps1` จาก commit ที่ตรวจแล้วและรันบน VPS ตัวติดตั้งจะสำรองข้อมูลก่อน build คืน source/build หาก build ล้มเหลว และไม่สั่งหยุดหรือรีสตาร์ต Node, Caddy หรือเกมอื่น ให้ตรวจข้อความ `MONTRA CHAT BUILD PASSED.` และ path backup

หลัง build ผ่าน เจ้าของ VPS จึงเปิดหรือรีสตาร์ตเฉพาะ process MONTRA ด้วย `MONTRA_CHARACTER_DIR` เดิม ห้ามปิด Node ทั้งเครื่อง หน้าเว็บใหม่จะแจ้งว่าเซิร์ฟเวอร์ยังไม่รองรับแชทจนกว่าจะติดตั้งฝั่ง VPS ห้ามรันทดสอบ integration กับ LIVE หรือเซฟจริง

หากต้องย้อนกลับ ให้สำรองเซฟล่าสุดแยกอีกครั้งก่อน คืนเฉพาะ build/source ที่เข้ากันได้กับเซฟปัจจุบัน ห้ามนำ backup เก่าเขียนทับความคืบหน้าล่าสุดโดยไม่ตรวจข้อมูล รายละเอียดการรักษาเซฟที่มี Map ID อยู่ใน [คู่มือ V0.2.8](WORLD-MAPS-WINDOWS-TH.md)
