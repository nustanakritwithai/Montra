# ระบบกิลด์

กิลด์ผูกกับช่องตัวละครถาวร แต่ละตัวละครอยู่ได้หนึ่งกิลด์ กิลด์มีสมาชิกได้ 30 คน หัวหน้าเชิญตัวละครที่อยู่ห้องเดียวกันได้ คำเชิญหมดอายุใน 60 วินาที หัวหน้าส่งตำแหน่งหรือให้อีกคนออกได้ หัวหน้าที่มีสมาชิกคนอื่นต้องส่งต่อตำแหน่งก่อนออก หากสมาชิกคนสุดท้ายออก ระบบยุบกิลด์ ชื่อกิลด์กลับมาใช้ใหม่ได้

สมาชิกและตำแหน่งเก็บใน `guilds.sqlite` ภายใน `MONTRA_CHARACTER_DIR` แยกจากเซฟตัวละครและ `economy.sqlite` คำเชิญเป็นข้อมูลชั่วคราวในห้อง สถานะออนไลน์ครอบคลุมห้องใน Node process เดียว ผู้เล่นในห้องอื่นเห็นข้อมูลกิลด์ร่วมกัน แต่คำเชิญเริ่มได้เฉพาะผู้เล่นที่อยู่ห้องเดียวกัน

การสำรองต้องหยุด MONTRA ก่อนและสำรองโฟลเดอร์ตัวละครทั้งชุด รวม `guilds.sqlite` และไฟล์ WAL/SHM หากมี พร้อมเซฟและฐานข้อมูลเศรษฐกิจ ตรวจการกู้คืนในโฟลเดอร์ทดสอบก่อนใช้จริง การปรับใช้ต้องมี `GuildStore.ts`, `MyRoom.ts`, `MyRoomState.ts` และหน้าเกมรุ่นที่รองรับกิลด์ ระบบนี้รองรับ Node process เดียว การขยายหลาย process ต้องเพิ่มฐานข้อมูลและกลไกกระจายสถานะร่วมกันก่อน

ทดสอบ `guild-store.test.ts` และ `guild-integration.mjs` ในห้องและโฟลเดอร์ทดสอบแยก ให้รัน integration ขั้น `write` รีสตาร์ตเซิร์ฟเวอร์ด้วยโฟลเดอร์เดิม แล้วรันขั้น `read` ผ่าน `MONTRA_GUILD_STAGE`
