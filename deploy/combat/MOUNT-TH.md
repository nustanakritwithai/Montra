# MONTRA — ม้าเดินทางรุ่นแรก

ทุกอาชีพเรียกม้าได้จากปุ่ม **เรียกม้า** ในแถบเมนู และกดปุ่มเดิมเพื่อลงม้า ไม่ต้องซื้อหรือมีไอเท็มม้า เซิร์ฟเวอร์กำหนดความเร็วเดินทาง 5.4 หน่วยต่อวินาที จากความเร็วเดินปกติ 3 หน่วยต่อวินาที ตัวเลขนี้เป็นค่าเริ่มต้นสำหรับทดลองเล่น

เรียกม้าได้เมื่ออยู่บนพื้นและพ้นการต่อสู้แล้ว ไม่สามารถเรียกระหว่างบิน ปีน พุ่ง ถูกควบคุม หรือกำลังใช้ท่าบางชนิด การเรียกม้าจะเก็บวิญญาณที่เรียกอยู่ ขณะขี่ต้องลงม้าก่อนโจมตี ใช้วิชาต่อสู้ บิน ปีน หรือพุ่ง หากถูกโจมตีหรือถูกควบคุมจะลงม้าอัตโนมัติ เมื่อวาร์ปหรือต่อเกมใหม่จะเริ่มบนเท้า

เซิร์ฟเวอร์ควบคุมสถานะและความเร็ว ผู้เล่นคนอื่นเห็นม้าของผู้ขี่ในห้องเดียวกัน การเดินใช้การตรวจชนแบบแบ่งช่วงตามขอบแผนที่และกำแพงเดิม โมเดลม้าเป็นรูปทรงสามมิติที่สร้างในเกม ไม่ต้องดาวน์โหลดไฟล์โมเดลเพิ่ม จุดชนยังใช้ขนาดตัวละครเดิม รูปทรงม้าอาจแทรกกับฉากแคบได้ จึงควรตรวจภาพและท่านั่งบนแผนที่จริง

## การติดตั้งและตรวจสอบ

เว็บและเซิร์ฟเวอร์ต้องใช้รุ่นที่รองรับ `mountAvailable` และ `toggle_mount` ตัวติดตั้ง Windows จะสำรองข้อมูลและ build ก่อนเริ่มเซิร์ฟเวอร์ด้วยวิธีปกติ `mount-integration.mjs` ใช้เฉพาะ Node instance แยกและโฟลเดอร์ตัวละครชั่วคราว ห้ามทดสอบกับเซิร์ฟเวอร์จริง
