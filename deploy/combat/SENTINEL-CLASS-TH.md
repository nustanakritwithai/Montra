# ผู้พิทักษ์ — แนวหน้าและคุ้มกัน

เลือกสายผู้พิทักษ์ที่ลานพัก แล้วเปิด **พิทักษ์** เพื่อเรียนวิชาและจัดได้ 4 ช่องลัด ค่าด้านล่างเป็นค่าทดลองสำหรับปรับสมดุลหลังผู้เล่นทดสอบ วิชาเดิมยันต์คุ้มกายและ Talent ผู้พิทักษ์ยังใช้ได้ตามเดิม

* **ตั้งรับ:** ตั้งง้าวรับศึกป้องกันด้านหน้า 2.5 วินาที; ย่างคุมแนวเข้าหาเป้าหมายและเพิ่ม DEF 12% 6 วินาที; หลักมั่นคงเพิ่ม DEF 8% เมื่อสวมง้าวผู้พิทักษ์; ปักหลักไม่ถอยเพิ่ม DEF 25% และลดความเร็วเดิน 40% เป็นเวลา 6 วินาที
* **ควบคุม:** ฟาดง้าวสกัดโจมตีและสตัน, กวาดเปิดแนวโจมตีมอนสเตอร์ด้านหน้าสูงสุด 3 ตัว, กระแทกหยุดศึกแสดงท่าร่าย 0.8 วินาทีก่อนโจมตีและสตัน (เดินไม่ได้ ถูกดาเมจขัดจังหวะได้ และเป้าหมายหลบออกนอกระยะได้), ง้าวพิทักษ์พิฆาตใช้หลังรับหรือสกัดสำเร็จภายใน 3 วินาที
* **คุ้มกัน:** เสียงท้าทายบังคับมอนสเตอร์ทั่วไปสูงสุด 3 ตัวให้เล็งผู้พิทักษ์ 3 วินาที โดยมอนสเตอร์มีช่วงต้าน 8 วินาที; คุ้มกันสหายเพิ่ม DEF 15% 8 วินาที; ยืนเคียงป้องกันก้าวหาเพื่อนและรับ 30% ของดาเมจแทนเป็นเวลา 6 วินาที; แนวพิทักษ์เพิ่ม DEF ปาร์ตี้ 12% 8 วินาที

สตันมอนสเตอร์ทั่วไป 0.7 วินาที ใช้ช่วงต้านร่วมกับสกิลขัดจังหวะมวย มอนสเตอร์ชั้นสูงและบอสต้านสตันและยั่วยุ สตันผู้เล่น 0.45 วินาทีและมีช่วงต้าน 4 วินาที ไม่บังคับเป้าหมายผู้เล่นด้วยการยั่วยุ การช่วยรับดาเมจรวมถึงการโจมตีจากวิญญาณที่ผู้เล่นเรียก และสิ้นสุดเมื่อหมดเวลา ผู้พิทักษ์หมดสติ เลิกอยู่ปาร์ตี้เดียวกัน ออกนอกแผนที่หรือห่างเกิน 6 เมตร

แต้มวิชาเริ่มที่ 1 และได้เพิ่ม 1 แต้มทุก 2 เลเวล วิชาขั้นสูงต้องเรียนวิชาก่อนหน้าและฝึกให้ครบ การฝึกรับและสกัดนับจากมอนสเตอร์ การช่วยเหลือนับเมื่อช่วยเพื่อนที่กำลังสู้กับมอนสเตอร์เท่านั้น การเรียน จัดช่อง และคืนแต้มทำที่ลานพักหลังพ้นการต่อสู้ 5 วินาที การคืนแต้มเก็บผลฝึกและคูลดาวน์เดิม

## การติดตั้งและข้อมูล

ใช้ตัวติดตั้ง Windows จาก revision ที่ผ่าน CI หลังเจ้าของหยุดเซิร์ฟเวอร์พอร์ต 4108 ตัวติดตั้งสำรองข้อมูลและ build ก่อนติดตั้งและไม่เริ่มเซิร์ฟเวอร์เอง เจ้าของเปิดเซิร์ฟเวอร์อีกครั้งและทดสอบหน้าเว็บ ระบบทดสอบ integration ต้องใช้ Node แยก พอร์ตที่ไม่ใช่ 4108 และโฟลเดอร์ montra-sentinel-test-* ชั่วคราว ห้ามชี้ไปยังข้อมูล LIVE

เซฟเก่าที่ไม่มีตำราผู้พิทักษ์จะได้รับตำราเปล่าเมื่อเลือกสายนี้ ส่วนเซฟสายอื่นและ Talent เดิมยังอ่านได้ ตำราใหม่มีข้อมูล sentinelBook หากย้อนกลับไปใช้เซิร์ฟเวอร์เก่าที่ไม่รู้จักฟิลด์นี้แล้วบันทึกทับ อาจสูญเสียความคืบหน้าตำราใหม่ จึงต้องเก็บ backup และตรวจแนวทางกู้คืนก่อน rollback
