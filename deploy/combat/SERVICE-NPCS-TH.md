# NPC ตัวแทนระบบในพื้นที่

NPC ผู้ให้บริการกระจายตามสถานที่ในห้องโลก เช่น ตลาด โรงช่าง ลานบัญชาการ ศาล และเส้นทางใกล้ค่าย แทนการรวมที่จุดวาร์ป เมืองหลักมีตัวแทนช่าง ตลาด กิลด์ ปาร์ตี้ เดินทาง ยุทธศาสตร์ ครูวิชา และผู้แนะนำ ด่านยุทธศาสตร์มีบริการกระจายตามจุดสำคัญ แต่ละบทบาทปรากฏซ้ำในหลายแผนที่ พื้นที่ที่เปิดเป็นสนามรบแยกไม่ได้เพิ่ม NPC บริการบนสนาม

แตะ NPC เพื่อคุย หากอยู่ไกลตัวละครจะเดินไปหาและต้องแตะอีกครั้ง แผนที่แสดงจุด NPC และมีรายชื่อสำหรับสั่งเดินไปหา ผู้เล่นยังต้องคุยที่ NPC เพื่อเปิดบทสนทนา

NPC เหล่านี้เป็นทางเข้าไปยังระบบเดิม เช่น ช่างเปิดหน้ากระเป๋าและงานช่าง นายหน้าตลาดเปิดตลาด เสนาธิการเปิดแผนที่ยุทธศาสตร์ และครูวิชาเปิดตำราของอาชีพปัจจุบัน ไม่มีการสร้างร้านขายไอเท็มหรือรางวัลใหม่ เงื่อนไขเซิร์ฟเวอร์เดิมยังใช้ เช่น ตลาดต้องเปิดเศรษฐกิจ การจัดวิชาบางอย่างต้องกลับลานหมู่บ้าน และสิทธิกิลด์วอร์ยังตรวจตามเดิม

NPC ภารกิจอยู่ตามเส้นทางใกล้ค่ายและให้เซิร์ฟเวอร์ตรวจระยะก่อนรับหรือยกเลิกงาน ตำแหน่งหลีกเลี่ยงประตู สิ่งกีดขวาง NPC อื่น และพื้นชัน ข้อมูลตำแหน่งส่งในแผนที่ห้องโลกและไม่แก้ตำแหน่งหรือเซฟของผู้เล่น ตำแหน่งใหม่ไม่ได้สร้างเขตพักหรือเปลี่ยนกฎต่อสู้ของพื้นที่

NPC ใช้โมเดลคนเดียวกับตัวละครผู้เล่นเป็นฐานชั่วคราว พร้อมสีและป้ายแยกบทบาท และยังใช้จุดแตะของ NPC เอง ไม่ถูกมองเป็นเป้าหมายผู้เล่น โมเดลสำรองยังทำงานได้หากโหลดไฟล์คนไม่สำเร็จ

## NPC สำหรับสงครามและบริหารเมือง

| NPC | ตำแหน่งและหน้าที่ |
|---|---|
| นายทหารรับศึก | อยู่ใกล้จุดเปิดศึกจริงของทุกแผนที่ที่รองรับสงคราม แผนที่พื้นที่แสดงเป็นจุดแดงอ่อน แตะแล้วเปิดกระดานศึก ผู้บัญชาการหรือนายทหารกดเปิดศึกจากกระดาน สมาชิกเข้าร่วมได้ตามสิทธิ์และสถานะศึก |
| นายคลังเมือง | เปิดสต็อกและการฝากวัตถุดิบที่สามลานและจันทรา นายคลังสามลานอยู่ในลานขยายคลังเพื่อให้เปิดโครงการและส่งวัสดุได้จากบริเวณนั้น |
| ช่างโรงงานเมือง | เปิดส่วนโรงงานที่สามลานและจันทรา ผู้เล่นที่ใช้โรงงานสาธารณะของสามลานได้จะเห็นคิวส่วนตัว |
| ผู้ประกาศภารกิจเมือง | เปิดกระดานงานที่สามลานและจันทราเพื่อดูงานเก็บแร่ ขนเสบียง และสัญญาจัดซื้อ การรับหรือส่งสินค้าที่ต้องพบตลาดยังทำกับนายหน้าของเมือง |
| นายหน้าตลาด | ที่สองเมืองเปิดตลาดประจำเมืองจากปุ่มหลัก และเปิดตลาดโลกได้จากบทสนทนา นายหน้าจันทราเปิดหน้าใบสั่งซื้อกิลด์ได้ด้วย |
| เสมียนศาลาว่าการ | อยู่ที่จันทราและเปิดหน้าบัญชีทองตลาด นโยบายเมือง และเสบียงเตรียมศึก |

จุดเปิดศึกใช้รัศมีเดียวกับธงหรือค่ายที่เซิร์ฟเวอร์กำหนด ผู้เล่นต้องผ่านการตรวจตำแหน่ง สิทธิ์ สถานะตัวละคร และการคุ้มครองพื้นที่ก่อนเริ่มศึก NPC เมืองแสดงตามระบบที่เซิร์ฟเวอร์เปิด และใช้สิทธิ์ตามผู้ครองเมืองเดิม
