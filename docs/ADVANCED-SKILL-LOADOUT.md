# Skill loadout interface

The previous two-bank interface is superseded by the [unified four-slot hotbar](UNIFIED-SKILL-HOTBAR.md). Core and learned advanced skills now use the existing panel and server-persisted mixed selections. Separate point budgets and legacy book progress are preserved.

Historical legacy advanced loadouts remain in character saves for compatibility. Do not remove or rewrite them during migration or rollback. Follow the matching-backend deployment and flag-off rollback procedure in the unified hotbar document.
