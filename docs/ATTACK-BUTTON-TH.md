# ปุ่มโจมตีจากหลอดเลือด

แตะหลอดเลือดขวาล่างเพื่อส่งคำสั่งโจมตีมอนสเตอร์เดิมครั้งเดียว โดยไม่เปิดหน้าตัวละครทับขึ้นมา ปุ่มรองรับ Enter/Space และคงข้อมูลเลือด มานา กำลังสำหรับโปรแกรมอ่านหน้าจอ ส่วนหน้าตัวละครยังเปิดได้จากปุ่มข้อมูลซ้ายบน

การกดค้างไม่ส่งคำสั่งซ้ำ และการปัดพุ่งไม่ยิงคำสั่งโจมตี การเดินเข้าเป้าและโจมตีต่อเนื่องยังใช้ระบบเดิมของเซิร์ฟเวอร์

แพตช์นี้เป็น frontend-only ไม่แก้ระยะโจมตี เซิร์ฟเวอร์ schema หรือข้อมูลผู้เล่น งานปรับระยะโจมตีไกลแยกไว้เพื่อติดตั้งเซิร์ฟเวอร์ภายหลัง

ทดสอบ production handlers กับ DOM จริงที่ 320/390/1366 px รวมแตะ คีย์บอร์ด กดซ้ำ ปัดพุ่ง การเลือกมอนสเตอร์ และสถานะไม่มีเป้าหมาย พร้อมทดสอบ client ตัวเต็ม 4 ขนาดจอโดยปิดการเชื่อมต่อ backend
