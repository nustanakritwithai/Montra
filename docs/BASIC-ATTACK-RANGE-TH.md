# ระยะโจมตีปกติและปุ่มหลอดเลือด

- ปรับเฉพาะการโจมตีปกติของผู้ร่ายเวทและพระจาก 15 เป็น 8 เมตร เป็นค่าปรับเพื่อทดสอบการเล่น โดยอิงระยะยันต์ตีตราและระยะเข้าต่อสู้ของวิญญาณผู้พิทักษ์ที่มีอยู่แล้ว
- ไม่เปลี่ยนระยะประชิด 2.8 เมตร ระยะสกิล ดาเมจ หรือคูลดาวน์ เซิร์ฟเวอร์ตรวจระยะสามมิติทั้งตอนรับคำสั่ง เดินเข้าหา และทำดาเมจ
- แตะหลอดเลือดขวาล่างเพื่อส่งคำสั่งโจมตีมอนสเตอร์เดิมครั้งเดียว การเดินเข้าเป้าและโจมตีต่อเนื่องยังใช้ระบบเดิมของเซิร์ฟเวอร์ ไม่มีตัวจับเวลาส่งคำสั่งซ้ำในเบราว์เซอร์
- หลอดเลือดยังคงแสดงทรัพยากร และรองรับ Enter/Space กับโปรแกรมอ่านหน้าจอ เปิดหน้าตัวละครผ่านปุ่มข้อมูลด้านซ้ายบนได้ตามเดิม
- ข้อความระยะอ่านจาก `buildCatalog.basicAttackRanges` ที่เซิร์ฟเวอร์ส่งมา หากต่อเซิร์ฟเวอร์เก่าที่ไม่มีข้อมูลนี้จะไม่แสดงค่าระยะที่คาดเดา

## การตรวจสอบและการเผยแพร่

ทดสอบ handler ฝั่งเซิร์ฟเวอร์ทั้ง PvE/PvP และสองอาชีพ ที่ขอบระยะ 8 เมตร ความสูง การเดินเข้าเป้า คูลดาวน์ และยกเลิกด้วยการเดิน รวมถึงระยะประชิดและสกิลเดิม ทดสอบ WebSocket บน localhost ด้วยข้อมูลชั่วคราวเพื่อยืนยันข้อมูลระยะและพิกัดตอนโจมตีจริง และทดสอบแตะ/คีย์บอร์ด/ปัดพุ่งในเบราว์เซอร์แบบแยกจากข้อมูลผู้เล่น

การเผยแพร่ Pages แก้ปุ่มทันที แต่ไม่เปลี่ยนระยะบน VPS โดยอัตโนมัติ ต้องตรวจ CI ของ commit ที่จะใช้งาน แล้วแยก staging/build/สำรองข้อมูลตามคู่มือติดตั้ง Windows เดิมก่อนอัปเดตเซิร์ฟเวอร์ ไม่มีการเปลี่ยน schema บันทึกตัวละครหรือย้ายข้อมูลในแพตช์นี้
